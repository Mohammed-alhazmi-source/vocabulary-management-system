# Vocabulary Management System 📚

An interactive, responsive web application designed to build, organize, and practice word lists efficiently with client-side state management.

## 🚀 Features
- **Add & Organize:** Easily add, edit, and manage vocabulary words.
- **Client-Side State:** Fast and seamless user experience with persistent local storage.
- **Modern UI/UX:** Clean, dark-themed interface built with a modular component mindset.

## 🛠️ Tech Stack
- **HTML & CSS** (Custom styling, responsive layouts)
- **JavaScript** (DOM manipulation, modular architecture, asynchronous flows)
